## 1. 已完成（可正常使用）

### 1.1 规则引擎（整个产品的核心）

- 规则串 → 步骤列表的解析器（`@@`、`@CSS:`、`@XPath:`、`@Json:`、`$.`、`$[`、`/`、`:` 标记）
- `@put:{…}` / `@get:{key}` 变量、`$n` 组引用、`##` 替换、`&&` / `||` / `%%` 顶层分隔符
- `getString` / `getStringList` / `getElement` / `getElements` 四种取值接口
- **5 种匹配器**：CSS（jsoup 语义 + 上游两套下标语法）、XPath（自研 1.0 引擎）、JSONPath（jayway 语义）、正则、分级正则
- **JS 引擎**：JavaScriptCore + `java` 门面（ajax/get/post/file/base64/hex/md5/urlEncode）+ `cookie`/`cache`/`source`/`book`/`chapter`/`result` 等脚本绑定
- JS 沙箱改为**能力白名单**（网络、沙箱内文件、Cookie、缓存、书源数据）
- 替换/净化规则引擎（书名与正文两个作用域）

### 1.2 书源 / 书籍 / 章节

- 书源实体与全部规则结构；RSS 源实体
- 搜索、发现、书籍详情、目录、正文（**含追页**）
- **换源**（按书名/作者检索、排序、进度迁移）与**按章换源**
- 书源登录（表单 / 登录脚本 / 内置 WebView 三种方式），RSS 源也可登录
- 书源校验（搜索 → 发现 → 详情 → 目录 → 正文 全链路 + 中文失效分组 + `// Error:` 注释）
- 更新目录（整表替换 + 按下标继承进度 + 新章节数量比较）
- 搜索正文（±20 字上下文）

### 1.3 数据层

- 完整 Room v75 schema（**21 张表**），表名与上游一致（保证备份兼容）
- 备份 / 恢复（15 张表 + `config.xml` 的 ZIP）、`servers.json` 的 AES-ECB 加密
- **WebDAV** 同步（`PROPFIND`/`PUT`/`GET`/`DELETE`/`MKCOL` + Basic 认证）
- 搜索缓存 / TTL 缓存 / 书源变量 / Cookie 持久化
- 分组位掩码、TXT 目录规则、词典规则、键盘辅助、HTTP-TTS 引擎

### 1.4 阅读体验（移植得最完整的一块）

- 页面模型 `TextPage` / `TextLine` / `TextColumn`（与上游 1:1 对应）
- 分页引擎（静态排版等价）、页面游标（上一页/下一页/下一章+1，跨章节）
- **5 种翻页方式**：覆盖 / 滑动 / 仿真 / 滚动 / 无
- 阅读状态机（预加载、进度保存、合并远端进度）
- **九宫格点击**（每个区域可绑定 15 种动作）+ 点击区域可视化编辑器
- 文字选择与 **8 个动作**（替换 / 复制 / 书签 / 朗读 / 词典 / 搜索正文 / 浏览器 / 分享）
- 页眉页脚 **TIP 系统**（14 种类型，可配置位置/颜色/对齐）
- 背景：纯色 / 图片 / 日夜 / 电子墨水；文字颜色与透明度
- 简繁转换（OpenCC 表：7,102 单字 + 38,972 词组，含上游排除表）
- 字体：系统字体 + 用户自定义字体文件（CoreText 注册）
- **内嵌图片**：按上游 `AppPattern.imgPattern` 切分，4 种样式（撑满宽度 / 适应边框 / 文字嵌入 / 默认），点击预览 + 长按菜单（显示/刷新/保存/菜单/选择文件夹）
- **连续滚动阅读模式**（上游 `ScrollPageDelegate` 的偏移量与跨页算法）
- **自动翻页**：3 种模式（翻页 / 滚动 / 进度）
- **朗读**：系统 TTS + HTTP TTS；段落高亮；流式音频播放
- **全部 28 项阅读偏好**（`pref_config_read.xml`）都有界面且生效（阅读器「更多设置」与应用「阅读设置」两处入口）
- 阅读风格导出/导入（`readConfig.zip`，与安卓版互通）

### 1.5 本地书 / RSS / 离线缓存

- **TXT**（含目录自动识别、长章节拆分）、**EPUB**、**PDF**、**UMD**、**MOBI/AZW**
- TXT 目录规则（可导入/导出/排序）

- **离线缓存**：下载队列、重试、进度、全书缓存、章节区间缓存、缓存管理界面、TXT/EPUB 导出
- 应用日志（上游同款内存环形缓冲，100 条）

### 1.6 集成与外壳

- **本地 HTTP API（26 个路由）**，响应使用上游 `ReturnData` 信封；**WebSocket API（3 个端点）**

## 4. 有意不做（Android 专属能力）

| 能力 | 原因 |
|---|---|
| 音量键翻页 | 需要 `UIApplication` 子类，SwiftUI 无法安装；改为点击/滑动/媒体键 |
| 自定义翻页硬件键（`customPageKey`） | iOS 没有可选的硬件键码 |
| 打开系统 TTS 设置（`sysTtsConfig`） | iOS 无对应系统页；朗读在应用内配置 |
| 媒体键唤醒应用（`mediaButtonOnExit`） | iOS 应用前台运行才有意义 |
| `optimizeRender`（安卓 Canvas 录制） | API 29+ 专有；偏好项保留 |
| 18+ 域名黑名单 | 上游分发渠道的内容策略，不是功能 |

另有 30 余条"有意偏差"（本地 API 加 Bearer 令牌、JS 沙箱改白名单、无 Cronet、无桌面小组件、EPUB 导出自研写入器、AES 用 Swift 实现以便在 Linux 验证等），详见 `Plan/00-feature-parity-matrix.md` 的「Deliberate deviations」。

## 5. 如何验证

```bash
# 编译 + 全部单元测试（Linux）
wsl -d Ubuntu -- bash /mnt/d/code/vscode/legado-ios/Scripts/sw.sh build
wsl -d Ubuntu -- bash /mnt/d/code/vscode/legado-ios/Scripts/sw.sh test

# 无头冒烟测试（schema → 分组 → 书源导入 → 书架 → 搜索 → 分页 → HTTP API）
wsl -d Ubuntu -- bash /mnt/d/code/vscode/legado-ios/Scripts/sw.sh run

# Apple 专属代码路径的类型检查（UIKit/AVFoundation/WebKit/…）
wsl -d Ubuntu -- bash /mnt/d/code/vscode/legado-ios/Scripts/typecheck_apple.sh
```

- iOS App 本体由 `project.yml`（XcodeGen）生成 `LegadoApp.xcodeproj`，**只能在 macOS 上编译**；仓库里的 macOS CI 负责这一步。
- Linux 上 UI 层通过手写的 SwiftUI shim（`Sources/LegadoUIShim`）**只做类型检查**，不渲染——界面效果需要在 macOS/真机上复核。
